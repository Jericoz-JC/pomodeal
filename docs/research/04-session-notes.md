## Scoring rubric (fill after the session)

| Signal | Score |
| --- | --- |
| Q1 bargaining described unprompted | 0 no · 1 when prompted · 2 unprompted |
| Q2 hardest moment | starting / staying / ending breaks / other |
| Q3 main distraction device | phone / laptop / both |
| T1 Quick Deal completed without help | 0 / 1 |
| Positive reaction in their own words | 0 none · 1 polite · 2 specific ("this is literally me at midnight") |
| Shame, babyish or medical reading | 0 none · 1 mild · 2 clear (counts toward the Gate 0 red line) |
| Intercept opt-in | 0 no · 1 one app · 2 several |
| Commitment | 0 declined · 1 took link · 2 used it and reported back |
